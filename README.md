# 🚀 Modern React Landing Page

A modern, responsive, and animated landing page built with **React**, **Tailwind CSS**, and **Framer Motion**. This project showcases clean UI design, smooth animations, reusable components, and a scalable folder structure following modern frontend development practices.

## 🌐 Live Demo

🔗 https://modern-project-in-react.vercel.app

---

## ✨ Features

- ⚛️ Built with React (Functional Components & Hooks)
- 🎨 Styled using Tailwind CSS
- 🎬 Smooth animations powered by Framer Motion
- 📱 Fully responsive across all devices
- ♻️ Reusable and modular components
- 🚀 Fast development with Vite
- 📂 Clean and scalable project architecture
- ⚡ Optimized performance and modern UI
- 💻 Easy to customize and extend

---

## 🛠️ Tech Stack

- React
- JavaScript (ES6+)
- Tailwind CSS
- Framer Motion
- Vite

---

## 📁 Project Structure

```
src/
│
├── assets/          # Images, icons, fonts
├── components/      # Reusable UI components
├── pages/           # Application pages
├── App.jsx          # Root component
├── main.jsx         # Application entry point
└── index.css        # Global styles
```

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/shameercodes/modern-react-landing-page.git
```

### 2️⃣ Navigate to the Project

```bash
cd modern-react-landing-page
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Start the Development Server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```

---

## 📦 Build for Production

```bash
npm run build
```

To preview the production build:

```bash
npm run preview
```
